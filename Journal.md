# Planet-O-Meter
## Phase 1

I used the Scanner class to get the user's input.
I used nextLine() for both the user's name and the planet's name.
I stored both input in String variables.
I used those variables in the welcome message.
I did not have an issue with the Scanner in this phase.

## Phase 2
I used an if/else statement to check the temperature.
I checked if the temperature was above 100 or below -50.
I used || because either condition makes the planet hazardous.
If either condition is true, the program prints a warning
Otherwise, the program says the temperature is acceptable.
I used if/else because there are two possible results: hazardous or acceptable.

## Phase 3
I used switch statement for the luxury rating.
I chose switch because program is checking specific numbers from 1 to 5.
Ratings 3 and 4 can share the same output.
Ratings 1 and 2 can also share the same output.
The default case handles any number that is not between 1 and 5.
An if/else if statement could also work, but switch is simpler for checking specific values.
